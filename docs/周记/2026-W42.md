2. **主线② · Ops Desk：运营 SOP 系统化（加厚）@李玲**  
   把原先散落在 Excel / 钉钉抄写 / 心算额度 / 对话对账里的动作，收成**本机可跑的 SOP 工作台**（Vue3 + FastAPI + SQLite，5177/8787，不接 Admin 实付）。本周在 W41 能力入库基础上，补齐对账结论只读页，并巩固全链路：  
   - **充值打款 SOP**：公司 × 云 × 金额 → 预览 / 下载付款申请 / 按月留档与删除。  
   - **开票 SOP（N1）**：抬头库复用 → 一键复制钉钉 → 月额度 50 万看板与超额拦截 → 税控导入 → 台账「去开票 / 已开票」联动。  
   - **海外收款 SOP**：Trinity USD Invoice 出单（不占国内开票额度）。  
   - **消耗台账 SOP**：扫客户结算多云预览；支持 Akamai 等币种筛选；与开票状态联动。  
   - **上游对账结论 SOP**：对话产出落 `上游对账/{供应商}/{账期}/` → Desk 列表 + 模型总览表只读展示（本周落地）。  
   提效：出单标准化、抬头零重复抄写、超开前置、消耗↔票可对、对账结论可复盘；钉钉 API 建单与上服务器部署仍为下一阶段。
