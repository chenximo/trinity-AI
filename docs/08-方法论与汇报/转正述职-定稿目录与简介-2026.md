## 第5页 · 主线① 定价系统（运营闭环）

**标题**：定价系统｜内部怎么定、审、写、对（0→1）

> **总分**：承接第4页 **维度 B**（工程化决策）的展开。  
> **和第6页必须分开**  
> - **本页 = 定价系统**：测算固化、价审写回、对账分柱——**管价的机器**  
> - **第6页 = 商业化**：计费、档位折扣、销售套件——承接第4页 **维度 A**  

### 闭环全景（建议画图）
```text
官方/上游价（L0/L1）
    → 测算固化定折规则（矩阵/底线）
    → 刊例价审：一点按钮出确认单 → 人确认写价（L2）
    → 系统可派生：对外报价稿 L3a / 商务底座 L3b
    → 月对账（平台成本 Token vs 上游实付）∥ 与「跟价改刊例」分柱
```

### 价格层（系统结构）
| 层 | 在系统里是什么 |
|----|----------------|
| L0 | 官方锚 |
| L1 | 进货/上游挂牌 |
| L2 | 线上基础刊例（确认写回后的扣费真源） |
| L3a / L3b | 由规则 + L2 **生成的表**（卖法见第6页） |

### 最优解测算 → 规则固化（答辩重点）

| 步骤 | 做什么 | 产物 |
|------|--------|------|
| ① 输入 | 成本折族、L2、竞品与约束 | 证据链、成本族分层 |
| ② 测算 | 各档折 × GM 护栏；对内五档/对外三档 | 多版对比选优 |
| ③ 固化 | 定折矩阵 + 底线 + 最深档 | **可复用定价规则** |
| ④ 生成 | 矩阵+L2→L3a 稿；底座→L3b | 表可出 |
| ⑤ 运营 | 改矩阵须确认再生；写回后检 GM | 可迭代 |

**口述金句**  
测算 → 矩阵护栏 → 价审写回 → 对账分柱 = **定价系统**，不是临时 Excel。

### 价审运营（可演示 · 系统能力）
**Before**：我自己跑脚本、传文件、对任务。  
**After**：一点按钮约 3 分钟出确认单；只做人确认写价。  
**省的是我自己的时间**（三人团队否则被重复劳动淹死）。  
- 出包环节约 **95%**（**仅出包；不含确认写价**）  
- 答辩：演示「触发 → 出确认单」或录屏  

### 对账（系统分柱）
成本核对 ≠ 跟价决策；样例核对做过。

**讲述节奏（约 1.5～2′）**  
分工一句 → 闭环图 → 测算固化 → 价审 Before/After → 对账一句。  
**本页不讲**：官网怎么卖、销售话术、预付费营销、赚钱两差展开（留给第6页）。
