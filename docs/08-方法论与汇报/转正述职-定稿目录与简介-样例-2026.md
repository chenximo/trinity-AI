```text
官方/上游价（L0/L1）→ 测算固化定折规则 → 刊例价审（一点按钮 → 人确认写价 L2）

```

【块：价格层 · 金字塔】

| 层 | 含义 |
| --- | --- |
| L0 | 官方锚 |
| L1 | 进货 / 上游挂牌 |
| L2 | 线上基础刊例 · 扣费真源 |
| L3a / L3b | 对外报价稿 / 对内商务底座 · 由规则 + L2 派生 |

【块：最优解测算 → 规则固化 · 表】

| 步骤 | 做什么 | 产物 |
| --- | --- | --- |
| ① 输入 | 成本折族、L2、竞品与约束 | 证据链 |
| ② 测算 | 各档折 × GM 护栏；对内五档 / 对外三档 | 多版选优 |
| ③ 固化 | 定折矩阵 + 底线 + 最深档 | **可复用规则** |
| ④ 生成 | 矩阵+L2 → L3a / L3b | 表可出 |
| ⑤ 运营 | 改矩阵须确认再生；写回后检 GM | 可迭代 |

【块：价审 Before/After + 对账】

- **Before**：人肉脚本 + 传文件  
- **After**：一点按钮 · 约 3 分钟出确认单 · 只做人确认写价  
- **出包 ≈ 95%**（**仅出包 / 出确认单；不含确认写价**）  
- **对账**：成本核对 ≠ 跟价决策；样例核对做过  

**口述**（约 2 分 30 秒 · **本页最重**）

> 展开维度 B：定价系统怎么定、审、写、对。L2 是扣费真源，L3a/L3b 派生。闭环图走一遍；价审 Before/After；95% 仅指出包。可演示「触发 → 出确认单」。本页不讲怎么卖——留给 P06。
