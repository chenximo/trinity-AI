# 账单对账

> 与价目/商务报价表区分：这里只放**实际账单核对**与配套**发票 / Invoice**。  
> 旧路径 `pricing/billing-reconciliation/` → 已迁入本目录。

## 一眼找

| 类型 | 路径 | 对谁 |
|------|------|------|
| **上游对账** | [`上游对账/`](./上游对账/) | 供应商月结（TokenHub / AIGC…） |
| **大客户对账** | [`大客户对账/`](./大客户对账/) | 按大客立卷；卷内再分下游 / 上游 |

```text
账单对账/
├── 上游对账/
│   └── <供应商>/YYYY-MM/
│       ├── …账单·平台导出·核对报告
│       └── 发票/                    ← 上游开给我们的票 / Invoice
│
└── 大客户对账/
    └── seedance-大客户/
        └── YYYY-MM-DD_至_YYYY-MM-DD/
            ├── 下游/                ← 客户侧（如 shilinrui）
            │   ├── …原价明细·平台导出
            │   └── 发票/            ← 我方开给客户的 Invoice / 发票
            ├── 上游/                ← 该客进货侧
            │   ├── …上游账单·成本导出
            │   └── 发票/            ← 上游开给我们的票（对应本账期）
            └── *核对*.xlsx
```

## 发票放哪

| 场景 | 目录 | 典型文件 |
|------|------|----------|
| 供应商月结票 | `上游对账/<供应商>/<月>/发票/` | PDF / 扫描件 / 电子发票 |
| 大客 · 我方开给客户 | `大客户对账/…/<账期>/下游/发票/` | Invoice（如 Trinity → FAR / 客户主体） |
| 大客 · 上游开给我们 | `大客户对账/…/<账期>/上游/发票/` | 上游 Invoice / 结算单 |

命名建议带：**日期 · 金额 · 票号或 Invoice No.**，便于和核对表对上。

## 规则

1. **账期文件夹**统一：`YYYY-MM-DD_至_YYYY-MM-DD`（大客）；常规上游用 `YYYY-MM`。  
2. **下游** = 客户账单 / 原价 ↔ 平台用量·扣费 + **我方开票**。  
3. **上游** = 进货成本 ↔ 上游账单 + **上游开票**。  
4. 整站供应商月结 → `上游对账/`；按大客立卷 → `大客户对账/`。
