## 0. 分类怎么分（建议）

**不要把所有公司揉成一张「总头部 / 总二梯队」榜**——赛道不同，不可比。

建议两维：

| 维 | 含义 |
|----|------|
| **赛道** | 和 Trinity 是「同台定价竞品 / 供应或基建 / 相邻 API 生意 / Infra」 |
| **梯队（赛道内）** | 该赛道里的相对位置：头部 · 腰部/二梯队 · 长尾；标注「研究用，非权威排行」 |

Trinity 自身：统一 LLM API 平台（刊例 + 多供应 + 商务洽谈）。对标时优先看 **赛道 A**；其余多为生态/合作/相邻参考。
