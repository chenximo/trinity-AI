## 2. 共用类型 · 存储

```typescript
type PricingBinaryArtifactMeta = {
  id: number;
  kind: string;   // catalog-excel | l3b-draft | l3a-draft | l3b-archive | l3a-archive | snapshot-routes
  modality?: string | null;
  fileName: string;
  sizeBytes: number;
  source: string;
  label?: string | null;
  meta?: Record<string, unknown> | null;
  createdAt: string;
};
```

一张 `pricing_binary_artifact` 表 + 对象存储；同 `kind`+`modality` **upsert** 当前版。

**鉴权**：Admin JWT。Worker 上传刊例用 `ADMIN_API_TOKEN`（同 JWT）。

**`kind` 约定**

| kind | 用途 |
|------|------|
| `catalog-excel` | 价目预览 `trinity-pricing-{modality}.xlsx` |
| `l3b-draft` / `l3a-draft` | 商务 latest draft |
| `l3b-archive` / `l3a-archive` | 归档版 |
| `snapshot-routes` | 生成时线路快照（可选落库） |

## 4. 上游抓价

**页面**：`/pricing/catalog` →「获取价格」

### POST `/v1/admin/pricing/upstream-sources/{vendorCode}/fetch`

**请求体**：`{ "sourceUrl": "https://…", "vendorName": "百炼" }`

**响应**（`PricingUpstreamFetchResult`）：

```json
{
  "vendorCode": "bailian",
  "status": "accepted",
  "message": "抓价任务已受理",
  "webhookConfigured": false,
  "logId": 42
}
```

**服务端行为**

1. 创建 fetch 日志记录  
2. **异步 Job 内嵌**执行已有 `pricing:supplier:*` CLI（按 `vendorCode` 映射）  
3. 成功更新「最近抓取时间」；**只更新上游数据，不写 `/v1/prices`**  
4. 若配置了 `ops-settings.upstreamFetchWebhookUrl`，可同时 POST 外调（增强，非必须）

**验收**：点「获取价格」→ `accepted` → Job 完成后时间戳更新。

## 5. 商务价格（一键生成闭环）

**页面**：`/pricing/commercial`  
**不写** `/v1/prices`。

### 5.1 流程

```text
点「生成定价包」
  → Job 内拉线路 snapshot（字段同「线路管理」导出）
  → rebuild_discount_tier_workbook.py → L3b
  → build_outward_quote_standard.py → L3a
  → 写入 artifacts（l3b-draft / l3a-draft）
  → 钉住本次矩阵快照（写入 draft meta）
改矩阵 → PUT matrix（confirm:true）→ 再生成
满意 → POST archive
```

**Python 真源（勿重写）**

| 产物 | 脚本 |
|------|------|
| L3b `商务洽谈折扣总表.xlsx` | `trinity-AI/apps/trinity-product/docs/ai-api-platform/commercial-billing/scripts/rebuild_discount_tier_workbook.py` |
| L3a `Trinity模型报价表.xlsx` | `trinity-AI/pricing/scripts/build_outward_quote_standard.py` |

### 5.2 POST `/v1/admin/pricing/commercial/generate`

**请求体**（Admin 已接）：

```json
{ "modality": "text", "matrix": [], "note": "" }
```

`modality`：`text` | `image` | `video` | `all`

**响应**（`PricingCommercialGenerateResult`）：

```json
{
  "modality": "all",
  "snapshotArtifactId": 1,
  "draftMetaArtifactId": 2,
  "webhookConfigured": false,
  "webhookAccepted": false,
  "l3bFileNameHint": "商务洽谈折扣总表.xlsx",
  "l3aFileNameHint": "Trinity模型报价表.xlsx",
  "note": ""
}
```

Job 完成后前端用 #2 取 `kind=l3a-draft&latest=1` 预览下载。  
若配 `commercialGenerateWebhookUrl` 可外调 Worker；**默认内嵌 Job 即可**。

### 5.3 线路 snapshot（Job 内部 · 字段契约）

`generate` 内调用，**HTTP 不暴露**。行字段须与「线路管理」导出可对账：

`modelId`、`modelName`、`vendor`、`routeName`、`priority`、`weight`、`rpm`、`tpm`、`discount`、`circuitBreaker`、`enabled`、`officialPriceSpec`、`routeCostSpec`

### 5.4 GET / PUT `/v1/admin/pricing/commercial/matrix`

**GET** 返回：`{ rows, version, editingRows? }`

**PUT** 请求体：

```json
{
  "rows": [],
  "confirm": false
}
```

`confirm: true` 时写入**生效配置**并返回 `{ version }`（替代单独 `POST …/confirm`）。

矩阵行对齐 Admin `MatrixRow`：`id`、`familyLabel`、`standardGm`、`plus`/`mid`/`growth`/`scale`/`enterprise`（各 `zhe`、`gm`）。

**硬规则**：对外仅 **$5k / $10k / $50k**；折底线 **5.5**。配置真源：`trinity-AI/pricing/config/public-ladder-matrix.json`。

### 5.5 POST `/v1/admin/pricing/commercial/archive`

```json
{ "modality": "all", "label": "v1.0", "note": "2026-08", "fromLatest": true }
```

归档 L3b + L3a + 矩阵快照；只读，新 generate 不覆盖已归档。

### 5.6 GET `/v1/admin/pricing/commercial/archives`

列表项含：`id`、`label`、`archivedAt`、`note`、`modality`、`matrixVersion`、`matrixSnapshot`、`l3bArtifactId`、`l3aArtifactId`、`l3bFileName`、`l3aFileName`。

**验收（商务）**：generate → 下载 L3a 可打开 → 改矩阵 confirm → 再生成 → 归档可查；全程未改 `/v1/prices`。
