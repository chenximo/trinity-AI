## 0. 一句话

```text
双轨：V1 = 线上当前刊例（快照）；V2 = 国际站优先派生刊例。
对比表双轨算全、结论保留；价审主看「V2 vs 线上」。
本轮写回：只采纳「V2 > 线上」的上浮；V2 更低的维持 V1（线上），不私自降价。
无国际站时 V2 回退「国内 CNY ÷ 6.5」——此回退是生成规则，不叫 V1。
百炼国际 / AIGC 国际等转售渠道 ≠ 刊例真源。
```

## 1. 背景与目标

| 项 | 说明 |
|----|------|
| **V1（对照轨）** | **线上当前刊例**（`GET /v1/prices` 快照）；价审「会不会涨/跌」只跟它比 |
| **V2（目标轨）** | 厂商官网 **国际站** 价优先；无国际站 → 国内 CNY ÷ **6.5**（国际-only 则 USD 直用） |
| **为什么双轨** | 价审要看相对现网差多少；可回切；历史对照不断档 |
| **本轮范围** | 含 **新上架模型**；生文 + **生图 + 生视频** 一并纳入同一策略 |

**明确不做（刊例生成）**

- ❌ 用 `bailian-intl`、AIGC 国际、TokenHub 等**转售挂牌**当 V2 刊例锚（混元 TokenHub intl 为产品破例，见 §7）  
- ❌ 静默改生产 `/v1/prices`（仍须价审 HITL 确认写回）  
- ❌ 删除 V1（线上快照）列或历史快照  

转售国际价仍可用于 **L1 进货对照**，与本文刊例策略分开。

## 2. 术语

| 名称 | 含义 |
|------|------|
| **L0 官方锚** | 厂商**自己的**官网/开放平台价目（见 `suppliers/official/`） |
| **官网·国内站** | 中国内地价目页（常见 CNY） |
| **官网·国际站** | 同一厂商面向国际的价目页（常见 USD）；**不是**云厂商转售国际站 |
| **刊例·V1** | **线上当前刊例**（生产 `/v1/prices`）；对比表有这一列即可，不再用「÷6.5 算法」冒充 V1 |
| **刊例·V2** | 有官网国际站 → 用国际站价；否则 → **国内÷6.5**（或国际-only USD） |
| **国内折算锚** | 生成 V2 时的回退：国内站 CNY ÷ **6.5**；**不是** V1 |
| **`listing_policy`** | 生效指针：`v1` \| `v2`；**默认 `v2`**（`v1`=维持线上不动） |
| **生效刊例** | `listing_policy` 指向的那一版；上游对比主结论、拟写回 L2 都跟它 |

汇率：V2 回退路径锁 **6.5**（`FX_LEGACY_065`）。配置里另有 `FX_LISTING=7.25` 用于其它 cascade，**不用于本策略回退**，避免混用。

## 3. 生成规则（伪代码）

```text
function listing_v1(model):
  # 对照轨：线上当前刊例（快照），不是重新用 ÷6.5 算一遍
  return online_prices[model]   # GET /v1/prices；无则 ⚠ 未上架

function domestic_fx_fallback(model):
  if L0 仅有国际站或国际厂商 USD:
    return official_usd
  if L0 有国内站 CNY:
    return domestic_cny / 6.5
  else:
    return ⚠ 缺锚

function listing_v2(model):
  if L0 有官网国际站价（同 modality / 同档 tierKey）:
    return official_international   # 通常已是 USD，不再 ÷6.5
  else:
    return domestic_fx_fallback(model)

function active_listing(model):
  return listing_policy == "v1" ? listing_v1(model) : listing_v2(model)
```

**分档**：比较与生成必须按既有 `tierKey` 对齐（见治理工作流 P3）；国际站缺某档时该档 V2 **回退国内折算锚并记 note**（产品 2026-08-07 已拍）。

**价审主指标**：`V2 vs V1` = **V2 vs 线上**（入/出 %）。未上架模型无 V1，只展示 V2 候选价。

### 3.1 本轮写回闸（2026-08-09 产品拍）

> **对比结论照留**（V1/V2 / V2vs线上 列不删）。  
> **拟写回 / 对外生效价** 另加商务闸，**不等于**裸跟 V2。

```text
function writeback_candidate(model):
  v1 = listing_v1(model)   # 线上
  v2 = listing_v2(model)
  if 无 v1:                # 未上架
    return v2 或 待上架价审
  if v2 相对 v1 有上浮（入或出任一明显更高）:
    return v2              # 本轮可调
  else:
    return v1              # 持平或更低 → 不动，维持线上
```

**生文 · 本轮仅拟上浮（其余降价项一律维持线上）**

| Trinity ID | 线上(V1) 入/出 | V2 入/出 | 幅度 | 动作 |
|------------|----------------|----------|------|------|
| `hy-mt2-plus` | 0.077 / 0.31 | 0.1 / 0.4 | +30% / +30% | **调至 V2** |
| `glm-5.2` | 1.23 / 4.31 | 1.4 / 4.4 | +14% / +2% | **调至 V2** |

**明确不调（V2≤线上，维持 V1）**：`deepseek-v4-flash` / `deepseek-v4-pro`、`kimi-k2.5` / `k2.6` / `k2.7-*` / `k3`、`minimax-m2.5` / `m2.7` 等（详见 V2 vs 线上对比结论）。

仍须价审 HITL 后写生产；本闸 **不自动**改 `/v1/prices`。


## 7. 官方价格采集（L0）· 必须准备项

### 7.1 数据模型（catalog / seed 目标形态）

每个上架模型（三模态）在官方侧应能表达：

| 字段 | 说明 |
|------|------|
| `docUrl` / `pricingUrl` · **domestic** | 国内站价目（可与现字段兼容） |
| `docUrl` / `pricingUrl` · **international** | 国际站价目；**无则空** |
| `currency` per region | 国内多为 CNY，国际多为 USD |
| `tiers[]` per region | 分档完整；禁止用转售简档反推 |
| `region` / `listingSource` | 生成 V2 时选用哪套锚 |

现有 catalog 的 `region: domestic | international_only | global` **不够单独支撑「同一国内厂商双站」**，落地时需扩展（例如 `pricingUrls: { domestic, international }` 或平行 seed key）。本文先定产品口径，schema 在实现 PR 中钉死。

### 7.2 采集原则

1. **只采厂商自己的价目页**（开放平台 / 开发者文档 / 官方 Pricing）。  
2. 国际站链接须可公开打开；写入 catalog 的 `international` 字段。  
3. 金额**只许来自该页明文**；无字段写 ⚠，禁止比例推算。  
4. 生图按「张/积分」、生视频按「秒/积分/次」等既有单位，国际站与国内站分别录。  
5. 新上架模型：上架清单 ∩ Trinity `trinity-map` → 先补 L0 双站（能采则采），再进 V1/V2 表。
