各位好，价审主链（触发 → Worker 出包 → 确认写价）我们这边 CLI/Worker/Admin 已 push，现缺 **价目预览 Excel 存储 API**，请按仓库文档实现 P1。

## 要做什么（P1）

实现 Admin 已对接的三条路由（multipart + JWT，与现网其他 admin pricing 接口一致）：

- `PUT /v1/admin/pricing/catalog/excel` — 登记某模态最新 xlsx（字段：`modality`, `source`, `file`）
- `GET /v1/admin/pricing/catalog/excel` — 列表（每 modality 当前最新一条）
- `GET /v1/admin/pricing/catalog/excel/{modality}/download` — 下载

响应 JSON 形状见前端：`TrinityAI-web/apps/admin/src/api/pricingOpsApi.ts` → `PricingBinaryArtifactMeta`

## 谁会用

1. **价审 Worker**（异步，价审成功后）：`source=worker-post-review`
2. **Admin 价目预览页**手传：`source=manual`

Worker 上传需运维配 `ADMIN_API_TOKEN`（Admin JWT）；仅 Ops Token 不够。
