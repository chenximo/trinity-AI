## 0. 一句话

```text
底座定原价与成本护栏
  → 线上刊例（L2）绝对价
  → 自助：广场「折扣分组」打模型原价（引流，免谈）
  → 商务：全模型 × 充值档报价表（打原价；大单以合同为准）
充值按面值入账；最终以实际账单为准。
不对充值金额打折；对外不讲「额度×倍率」母语。
```

---

## 1. 总原则（硬口径）

| # | 原则 | 说明 |
|---|------|------|
| 1 | **预充值 + 绝对价** | Credits 入账后按模型单价扣费；主叙事不是 NewAPI 倍率 |
| 2 | **折扣只打模型原价** | `扣费 = 模型刊例(原价) × 适用折扣`；**不对充值面值打折** |
| 3 | **以账单为准** | 广场/Excel 为展示与评估；结算以调用账单为准 |
| 4 | **原价单一真源派生** | 模型原价在底座维护；官网分组价、梯度报表从底座/L2 生成，禁止三处手改原价 |
| 5 | **成本不对客** | 成本折、GM、二转线路只进对内表；对外只给绝对价或「相对刊例约 x 折」 |
| 6 | **供应不暴露** | 官 Key / 云 MaaS / 二转仅对内；二转不进客户价目与引流特价组主承诺 |

## 2. 价格层（L0–L3，沿用总览）

| 层 | 名称 | 对客？ | 本方案中的角色 |
|----|------|--------|----------------|
| L0 | 官方刊例锚 | ❌ | 对照与证据 |
| L1 | 进货/渠道挂牌 | ❌ | 成本与选路 |
| **L2** | 线上基础刊例 | ✅ | **模型原价（刊例）**；价审写回后的卖价锚 |
| **L3a** | 对外标准报价表 | ✅ 外发 | 销售可发 Excel：全模型 × 充值档绝对价 |
| **L3b** | 商务洽谈底座 | ❌ | 成本族 × 可谈档 × GM；**所有价格设置的对内来源** |

关系：

```text
L0/L1 ──对照──► L2 刊例（原价）
                 │
                 ├─► 广场折扣分组价 = L2 × 分组系数（如 0.9）
                 ├─► L3a 报表列 = L2 × 充值档系数（展示绝对价）
                 └─► L3b 谈单：在 L2/L3a 上再谈合同价（看成本护栏）
```

### 3.2 ② 官网 / 模型广场（自助）

| 项 | 约定 |
|----|------|
| **找模型** | **提供商**筛选为主（OpenAI、Anthropic、DeepSeek…）；可选粗「系列」快捷（GPT / Claude / 国内 / 其他国际），与提供商勿重复两套主路径——**首版建议保留提供商，系列作可选** |
| **改价格** | **折扣分组（当前计价）**：标准（1.0）/ 引流组（如 0.9）… |
| **计费方式** | 按量 / 按次：仍叫「计费方式 / 定价类型」，**不要**和折扣分组混在同一标题下 |
| **谁用** | 免商务谈判的自助客户；用于引流 |
| **扣费** | Key/工作区绑定当前折扣分组 → `L2 × 分组系数` |
| **展示** | 列表始终显示**当前分组下的绝对价**（可附「约刊例 0.9 折」） |

**广场 IA（推荐）**

```text

筛选
  提供商：全部 | OpenAI | Anthropic | …
  计费方式：全部 | 按量 | 按次
  （以后）模态：对话 | 生图 | 生视频
```

## 4. 两条客户路径（勿混）

```text
路径 A · 自助引流
  充值（面值）→ 选折扣分组 → 按分组价扣模型费 → 账单

路径 B · 企业商务
  充值达档 / 意向 → 发 L3a 报表 → 洽谈 → 合同价覆盖分组价 → 账单
```

| | 路径 A | 路径 B |
|--|--------|--------|
| 价格依据 | 广场折扣分组 | 合同价（相对 L2/标准组谈定） |
| 是否必须谈判 | 否 | 是 |
| 充值达档作用 | 可作「可谈资格」提示；**不必**自动改广场价 | 触发商务；合同生效后锁定 |

**禁止折上折**：合同价相对 **L2 / 标准组**，不要在「已选 0.9 组」上再乘合同折。

## 5. 折扣分组（自助）细则

### 5.1 首版建议

| 分组 code | 对外名 | 系数（相对 L2） | 模型范围（建议） | 备注 |
|-----------|--------|-----------------|------------------|------|
| `standard` | 标准价 | 1.0 | 全量可售主供模型 | 默认 |
| `promo_90` | 特惠 0.9 | 0.9 | 优先「可承受毛利」的模型集；或全量但须底座过护栏 | 引流；上线前用 L3b 验穿 |

> 系数与范围以商务底座验算后拍板；上表为产品占位。

### 5.2 规则

1. 分组价 = **绝对价**（由 L2 × 系数生成），对外主列不写倍率。  
2. 调用绑定：**一个 Key / 工作区同一时间一个分组**。  
3. 特惠组不得依赖二转履约对外承诺。  
4. 签约客户：合同价优先；限制再切更低引流组（或隐藏选组）。

## 6. 充值档（报表列 · 商务用）

门槛沿用证据链；**公开定折矩阵已拍（2026-08-04）**；L3a 报价表按此生成（脚本 `build_outward_quote_standard.py`）。

| 档位 | 门槛 | 报表列含义 |
|------|------|------------|
| **Standard** | &lt; **$1k** | = L2 **刊例（1.0）** |
| **Plus** | ≥ **$1k** | L2 × 公开定折 → 绝对价 |
| **Mid** | ≥ **$5k** | 同上 |
| **Growth** | ≥ **$10k** | 同上 |
| **Scale** | ≥ **$50k** | 同上 |
| **Enterprise** | ≥ **$100k** | 同上 |

- **折扣只打模型原价**；不对充值面值打折。  
- **多线路同模**：取商务表 **推荐/更厚成本族** 再查下表。  
- **0.75 族**：可能含备选线路；公开阶梯仍先按下表（不对外暴露备选）。  
- **≥0.78（无单模特例）**：L3a 阶梯暂 **原价**；`claude-opus-4-6` 走单模特例。  
- **L3b 商务深折**不得原样抄进 L3a。

### 6.0 公开定折总览（折 · GM）— 定稿

刊例≈挂牌；\(GM=1-d_{cost}/d_{sell}\)。Standard = 刊例，不列入。

**GM 护栏**：Plus～Growth 目标 **≥15%**（0.75 自 Growth 起可略破）；Scale 约 **≥12%**；Enterprise 约 **≥10%**（0.75·Ent ~8.5% 已接受）。

| 成本折 / 特例 | Plus | GM | Mid | GM | Growth | GM | Scale | GM | Enterprise | GM |
|---------------|------|-----|-----|-----|--------|-----|-------|-----|------------|------|
| **0.65** | **8.8** | ~26% | **8.5** | ~24% | **8.2** | ~21% | **7.6** | ~14.5% | **7.2** | ~10% |
| **0.70** | **9.0** | ~22% | **8.8** | ~20% | **8.5** | ~18% | **8.0** | ~12.5% | **7.8** | ~10% |
| **0.75** | **9.2** | ~18.5% | **9.0** | ~17% | **8.7** | ~14% | **8.5** | ~12% | **8.2** | ~8.5% |
| **`claude-opus-4-6`** | **9.8** | 视成本 | **9.5** | 视成本 | **9.2** | 视成本 | **9.0** | 视成本 | **8.8** | 视成本 |

> 表内 **9.0 / 9.2** = 九折 / 九二折（与脚本折数编码一致）。

### 6.1 硬约束与特例说明

| # | 约束 |
|---|------|
| 1 | 单位 GM 按 §6.0 护栏；破线不得用该折（已接受的格子除外） |
| 2 | 后档折数须 **≤** 前档（更深或持平仅当 GM 顶死） |
| 3 | 按成本族分折；单模特例覆盖族默认 |
| 4 | 不对充值打折 |

**单模特例**：`claude-opus-4-6` 全档见 §6.0（商务归属多为 0.78，公开不按 0.78 族、改走特例）。

**与证据链**：旧「Plus 统一 9.0」等由 §6.0 **取代**（对外）；L3b 仍可对内保留。
