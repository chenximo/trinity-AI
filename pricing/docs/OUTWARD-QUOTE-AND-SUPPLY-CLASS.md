## 0. 一句话

```text
对内：官 Key / 云 MaaS / 二转 三类都打标，进成本、选路、毛利、对账
对外：只卖「标准档」（+ 可选「高可用档」）绝对价；二转不进客户价目
缺的第一件成品：标准对外报价表（销售可发）≠ 商务洽谈折扣总表
```

> **2026-08-04 补充**：模型广场另有自助「折扣分组」（如 0.9，打模型原价、免谈引流），与本文 L3a「充值档报表」分工见 [定价方案 v0](./定价方案-v0-三件套与广场.md)。L3a Excel 初版已出：`trinity-outward-quote-standard.xlsx`。

## 1. 供应分类（对内必填）

| 代码 | 名称 | 地位 | 典型来源 |
|------|------|------|----------|
| `official_key` | 官 Key | 核心主供 | 原厂协议 Key / 官方直连 |
| `cloud_maas` | 云 MaaS | 核心主供 | Azure、Bedrock、Vertex、百炼、TokenHub 等云挂牌 |
| `relay_l2` | 二转 | 最差备线 | 再转售 / 中转上游（仅 failover） |

**线路台账建议字段**（运营真源，不对外）：

| 字段 | 说明 |
|------|------|
| `supplyClass` | `official_key` \| `cloud_maas` \| `relay_l2` |
| `routeRole` | `P1_primary` \| `P2_secondary` \| `failover_only` |
| `costAnchor` | 成本底（与商务成本折族对齐） |
| `eligibleOutwardTier` | 见 §2；二转固定 `none` |

## 2. 供应 → 对外档（映射规则）

| 对外档 | 客户说法 | 允许的供应分类 | 选路规则（建议） |
|--------|----------|----------------|------------------|
| **标准档** `standard` | 默认调用价 | 仅 `official_key`、`cloud_maas` | 在启用主供中按 P1/权重选；**禁止**落到二转后仍按标准档承诺 SLA |
| **高可用档** `ha`（可选） | 更高可用 / 双主供 / 指定云区域 | 仅 `official_key`、`cloud_maas`（建议 ≥2 条可用主供或指定区域） | 可略贵或同价；合同可写更严可用性 |
| **（不对客）备线** | — | `relay_l2` | 仅主供全挂后切换；**报价表不出现**；扣费默认仍按标准档，或走熔断/降级策略（产品另定） |

### 2.1 硬规则

1. **二转不得**映射为对外「特价档」或客户自选分组。  
2. **二转成本更低 ≠ 刊例更低**：差额进毛利缓冲，不压公开标准价。  
3. 商务深折只叠在 **标准/高可用刊例** 上，且合同绑定可履约主供（官 Key / 云 MaaS）。  
4. 对外文案禁止写「官 Key / 云 MaaS / 二转 / 逆向 / 倍率」；对内台账保留分类。

### 2.2 与 APIhub「分组倍率」对照（研究结论）

| APIhub | Trinity |
|--------|---------|
| 客户自选分组（含逆向） | 客户最多选 **标准 / 高可用** |
| 倍率÷刻度讲折扣 | 对外主列 **绝对价**；可选附「约官网 x 折」 |
| 统一价 Excel 外发 | **要补**同等角色的对外表 |
| 通道价差全暴露 | 通道差对内消化；二转不曝光 |

## 3. 对外报价表规格

### 3.1 定位

| | 对外报价表 | 商务洽谈折扣总表 |
|--|------------|------------------|
| 受众 | 销售外发、客户评估 | 销售/商务内部 |
| 内容 | 模型 × 档 × 绝对价 | 成本折族 × 客户档 × GM |
| 二转/成本折 | ❌ | ✅ |
| 是否公开站 | 可先 Excel/PDF；后挂 Pricing | ❌ 不上网深折 |

### 3.2 字段（最小集）

| 字段 | 必选 | 说明 |
|------|------|------|
| `modelId` | ✅ | Trinity 模型 ID |
| `displayName` | ✅ | 显示名 |
| `modality` | ✅ | text / image / video / … |
| `outwardTier` | ✅ | `standard` \| `ha` |
| `inputPrice` | ✅ | 目录价绝对价 |
| `outputPrice` | ✅ | 目录价绝对价（按次计费可空，见 unit） |
| `volumeTierPrices` | ✅ | Plus→Enterprise：目录价 × 对客折（展示绝对价 + 折数） |
| `cachePrice` | ✅ | **目录价·原缓存价**（无刊例标「—」）；充值档阶梯列暂仍只含入/出 |
| `currency` | ✅ | USD / CNY |
| `unit` | ✅ | per_1M_tokens / per_request / per_second … |
| `officialRefDiscount` | 选 | 相对官网约 x 折；须可核对，勿编 |
| `effectiveFrom` | ✅ | 生效日 |
| `notes` | 选 | 区域、上下文等；禁写供应黑话 |

### 3.3 Sheet 建议（已落地初版）

| Sheet | 用途 |
|-------|------|
| `00_说明` | 口径、与商务表边界、免责 |
| `01_标准档报价` | **主外发表**：目录价入/出/**原缓存价** + Plus→Enterprise 阶梯绝对价（入/出，标折数） |
| `02_高可用档` | 可选；本初版未建 |
| `99_对内索引_勿外发` | 模型 × 映射成本折；勿外发 |

**与数据宝 / 商务表分工：**

| 物料 | 是否外发 | 内容 |
|------|:--------:|------|
| `trinity-outward-quote-standard.xlsx` | ✅ | 目录价 + 商务阶梯折算绝对价（USD） |
| `商务洽谈折扣总表.xlsx` | ❌ | 成本族 × GM × 线路；算折真源，保持独立不改 |
| 缓存命中列 | ✅ | 目录价列展示原缓存价；阶梯列暂不含缓存 |

### 3.4 数字从哪来

```text
柱① 已校验线上刊例（/v1/prices 或价审确认值）→ 目录价列
        +
商务洽谈折扣总表 01 对客折 × 02 推荐成本折 → 阶梯列绝对价
        ↓
对外报价表（可发）
        ↓ 更大用量 / 点名特价
商务单客户合同价（仍可回查对内表）
```

**禁止**：用二转挂牌或中转站统一价直接当对外标准档；外发表不写 GM / 成本折 / 线路名。

## 6. 给老板的三句

1. 三类上游都要进**对内供应与成本**；对外报价只融官 Key + 云 MaaS。  
2. 二转只做备线与毛利缓冲，不进客户价目、不压刊例。  
3. 立刻补的是**标准档对外报价表**；倍率/分组是中转站话术，我们借「分档+统一表」，不借「逆向自选价」。
