# Trinity 销售建议书（对内）

> **读者**：销售、商务（内部作业手册，**默认不随客户包外发**）  
> **产品对外名**：AI API 聚合产品  
> **版本**：v0.2 · 2026-09-07  
> **关联物料**：A4 宣传单 · 宣讲 Deck · 对外 `Trinity模型报价表.xlsx` · 对内 `商务洽谈折扣总表.xlsx`

## 0. 一句话

```text
本文件 = 进商务时「怎么谈、怎么选档、发什么、什么不能说」

```

## 1. 什么时候用

| 阶段 | 你做什么 | 带什么 |
|------|----------|--------|
| 首次触达 | 讲清是什么、适不适合 | A4；需要则约 Deck |

| 收口 | 确认开通、对接、合同 | 法务文本；试用写「联系商务」未拍则不写死 |

---

## 2. 30 秒口径（开口用）

- **是什么**：一个 OpenAI 兼容 API，接入百余模型；预付费按量；可做工作区 / 成员 / Key / 限额。
- **解决什么**：多厂商接口不一、账单分散、选型试错、成本与权限难管。
- **怎么买**：预充值 Credits → 按量扣；档位越高商务可谈空间越大；开通走商务。
- **下一步**：看 Pricing / 模型目录 → 定档与充值 → 开通 Key → Docs / IDE 接入。

不适合硬推：只绑单一厂商、完全无聚合与管控诉求的客户——可诚实说，省时间。

---

## 3. 怎么选档（对内判断）

与官网浅档、Deck「怎么买」对齐；**「最高可省」是示意上限，不是合同固定折**。

| 档 | 门槛示意 | 对外怎么说 | 对内注意 |
|----|----------|------------|----------|
| 标准版 | 充值 &lt; $1,000 | 起步 · 刊例计价 | 少谈深折；先跑通 |
| 进阶版 | ≥ $1,000 | 商务优惠 · 最高可省约 10% | 对内查洽谈表再报价 |
| 成长版 | ≥ $10,000 | 商务优惠 · 最高可省约 18% | 可谈中间档，不写进公开页 |
| 企业版 | ≥ $100,000 | 专属方案 · 最高可省约 28% | 专属条款走商务+法务 |

**选档口诀**：先问「大概愿意预充多少 / 月耗量级」→ 落最近一档 → 用对内表算可谈空间 → 客户只看对外表或确认函数字。

## 5. 话术卡片（短）

| 场景 | 可以说 | 别说 |
|------|--------|------|
| 开场 | 「先确认你们是统一接入、控成本，还是 Coding/IDE 为主。」 | 一上来报死折 |
| 讲价值 | 「一个 API、少账单、场景选模、企业可管可控。」 | 未实测的延迟/吞吐对打 |
| 讲价 | 「刊例与阶梯在对外价目表；档位优惠是示意上限，以商务确认为准。」 | 「保证省 xx%」 |
| 试用 | 「试用额度联系商务开通。」 | 未拍死的金额/天数 |
| 竞品 | 「多套 SDK / 多份账单的痛我们一起收。」 | 点名贬低、抄竞品对比长文 |
| 收尾 | 「确认档位与充值 → 开通 → 技术对接；合同走法务。」 | 代替法务解释条款 |

## 6. 红线（首页级别）

1. 客户附件不得含商务深折表、成本族、供应分类黑话（官 Key / 二转等）。
2. 未上线 SLA、未拍试用/老带新数字 → 只说「联系商务」。
3. 「最高可省」≠ 固定折数；开通与折扣以商务书面确认为准。
4. 不编造客户名；场景示意须标明非签约案例。
5. 协议终稿归法务；本文件不是合同。
