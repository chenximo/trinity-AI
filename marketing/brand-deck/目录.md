## 结构原则

| 原则 | 说明 |
|------|------|
| 三层分工 | **能力页**讲「有什么」（P06–P07 API / P12–P13 云）→ **对照页**讲「相对谁更强」（仅 API · P08；云对照见官网）→ **FAQ**讲「客户会问什么」（P17） |
| 先品牌、后闭环 | P01–P04 建立认知后，直接进入 API / 云各自闭环，避免前半段重复讲壁垒 |
| 单产品可独立读完 | 每条产品线：是什么 → 能力 →（API 有壁垒）→ 场景 / 落地 → 合作/报价指引 |
| 场景必写 | 云侧「场景与落地」合页；标杆客户可占位「即将更新」 |
| 报价是指引 | 不贴成本/深折明细表；API 档位示意 + 云「联系商务」；**下一步 CTA 并入 P10** |
| 品类对照 | API 壁垒页用「直连原厂 / 纯转发聚合」等品类对照；云侧对照以官网为准，本册不重复 |
