## 结构原则

| 原则 | 说明 |
|------|------|
| 单产品可独立读完 | 每条产品线：是什么 → 功能 → **核心壁垒** → 场景 → 合作/报价指引 |
| 优势是主轴 | 用「品类对照 + 可验证能力」，**不点名竞品** |
| 场景必写 | 应用场景为正式页；标杆客户可占位「即将更新」 |
| 报价是指引 | 不贴成本/深折明细表；API 档位示意 + 云「联系商务」 |
