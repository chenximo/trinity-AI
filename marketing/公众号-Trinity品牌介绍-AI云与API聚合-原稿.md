### 开篇

数字化走到今天，很多企业其实卡在同一类问题上：

- 云要买阿里云、腾讯云、AWS、Azure……账号、账单、发票各搞一套  
- 大模型要接 GPT、Claude、国产模型……接口不一、成本难控、团队权限更乱  
- 业务要的是「能上线、算得清、管得住」，而不是再多签几份分散合同  

**Trinity** 面向企业，提供同一品牌下的两条能力：

> **企业数字化双引擎——多云资源集采 + 全球模型统一 API。**  
> 云资源 + 模型 API，同一品牌交付。

### 一、产品介绍：Trinity 是什么

**Trinity** 是面向企业的数字化服务品牌，当前重点包含两块业务：

| 业务 | 一句话 | 解决什么 |
|------|--------|----------|
| **Trinity AI 云** | 一站式多云采购与管理 | 多云开通、渠道优惠、账单发票、上云咨询 |
| **Trinity AI API** | 1 个 API，接入全球模型 | 对话 / Coding / 多模态统一调用与团队管控 |

合在一起可以理解为：

- **底层**：把主流公有云资源集采、管好、算清  
- **上层**：用一套兼容入口调用全球顶尖模型  
- **交付**：透明计费、企业管控、专属技术保障  

官网（两条业务线，分别进入）：

- **Trinity AI 云**：[trinitydesk.com](https://trinitydesk.com/)  
- **Trinity AI API**：[trinitydesk.ai](https://trinitydesk.ai/)

### 二、功能特性

#### （一）Trinity AI 云 · 多云集采

官网首页主叙事：**云资源集采整合 · 一站式多云采购与管理。**

覆盖主流公有云，包括：

**阿里云 · 腾讯云 · 华为云 · AWS · Google Cloud · Azure**

核心能力（对齐宣传单与云官网）：

1. **一站式多云采购**  
   统一咨询与开通管理，厂商官网资源、集采渠道代购。

2. **渠道优惠 + 透明服务费**  
   依托集团体量议价，企业可享大客户级折扣与灵活账期；**消耗计费 + 固定服务费，不赚差价、无隐性捆绑**。

3. **三大「零」承诺**  
   **零门槛 · 零保底 · 零承诺**——无年框锁定，按实际用量弹性使用。

4. **统一账单与开票**  
   统一账单、灵活开票或多抬头；开户、续费、对账专人跟进。

5. **上云全托管式服务**  
   免费上云咨询、架构设计、配置推荐、多云成本统一管控；渠道体量 + VIP 通道，问题优先响应。

相对「自己上各云官网散买」，更强调：**价格与账期优势、架构师配置推荐、1v1 售后与对账闭环**。

#### （二）Trinity AI API · 模型聚合

宣传单主标：**1 个 API，接入全球模型。**

核心能力：

1. **统一 API 入口**  
   兼容 OpenAI / Anthropic 等常见格式，存量系统可平滑接入。

2. **全模态覆盖**  
   对话 · AI Coding · 文生图 · 文生视频，一套 Key 调通；目录 100+ 款模型（以官网目录为准）。

3. **多源调度与高可用**  
   主流模型多源供应 + 智能路由：负载感知调度、异常自动转移，高峰与抖动时更稳、空等更少（同等模型能力下，优化的是端到端体验，而非改写模型本身）。

4. **专属容量与可预期吞吐**  
   相对公共共享池挤兑，平台侧采用与供应方约定的容量预留思路，高峰并发下时延与吞吐更可预期，便于容量规划。

5. **成本与体验优化**  
   auto 智能路由 + Trinity Memory：按任务选更合适的模型，减少重复上下文浪费（不对外承诺固定省钱比例）。

6. **企业管控**  
   工作区 / 成员权限 / API Key 批量下发 / 子区限额与用量；密钥可分级管控与轮换。

7. **可观测与对账**  
   用量、时延与失败可追溯；费用构成清晰，支撑财务核对与业务复盘。

8. **开发加速**  
   Claude Code / Codex / OpenCode 等 IDE 与 Agent 工作流一键接入；文档与对接示例齐全。

9. **合规友好**  
   **纯转发 · 零存储 · 数据不落盘**（请求与响应不持久化，便于企业合规评估）。

### 三、运用场景

#### 「AI 云」场景

- 多云资源要统一采购、统一开票，不想每个云商各签一套  
- 希望享受集采级折扣与灵活账期，又不要年框保底绑死  
- 需要上云架构咨询、配置推荐、费用与发票专人跟进  
- 业务同时用国内云与海外云（阿里云 / 腾讯云 / 华为云 + AWS / GCP / Azure）

#### 「AI API」场景

| 场景 | 适合做什么 |
|------|------------|
| **性价比对话** | 日常问答、批处理、客服辅助 |
| **AI Coding** | 写代码、改项目、编程助手与 Agent |
| **多模态生成** | 图文理解、生图、生视频，营销与内容产线 |

#### 「组合交付」场景

很多客户最终要的是：

> **底层上云 + 上层调模型**——算力与模型入口都在同一品牌下谈清楚、管清楚。  

适合：一边扩云资源，一边把大模型能力嵌进业务 / IDE / 内容产线的企业团队。

### 四、怎么合作 · 怎么计费（两套口径，勿混）

#### AI 云

- 开通、计费与折扣：**联系商务洽谈专属方案**  
- 计费原则：**透明**——消耗计费 + 固定服务费；不赚差价、无产品捆绑  
- 合作流程：咨询 → 方案与报价 → 开通 → 使用与对账 → 售后护航（以商务对接为准）

#### AI API

- **预充值 Credits → 按量扣费**（价格以刊例 / 商务折扣为准）  
- **充值越高，可洽谈空间越大**（「最高可省」为相对刊例上限示意，非固定折数）  

| 档位示意 | 门槛示意 | 对外说法 |
|----------|----------|----------|
| 标准版 | < $1,000 | 刊例起步 |
| 进阶版 | ≥ $1,000 | 最高约可省 10% |
| 成长版 | ≥ $10,000 | 最高约可省 18% |
| 企业版 | ≥ $100,000 | 最高约可省 28% |

**重要**：上表 **仅限 AI API 聚合**；**AI 云不计此档**。合同折扣、账期与 SLA 面议。

共同承诺（宣传单信任条）：

- 无隐性消费  
- 无产品捆绑  
- 数据自主可控

### 五、为什么选 Trinity

> 优势来自资源供给、智能调度、生态合作、平台工程与交付体系的协同——**同等模型下，把生产级调用跑得更稳、更省心**；云侧则把多云采购与账单管清楚。

**品牌层（双业务共通）**

1. **一个品牌，两条腿**：云资源集采 + 模型统一 API，可单买也可「上云 + 调模型」组合  
2. **算得清**：云侧透明服务费、不赚差价；API 侧预付费按量、刊例可见  
3. **管得住**：云账号费用发票可跟进；API 工作区 / Key / 限额可治理  
4. **进得去**：六大公有云一站对接；模型侧兼容主流协议、IDE 可一键接入  

**AI API：和其他用法比，强在哪**

很多人以为聚合平台只是「换个调用地址，模型还是原来那个」。  
Trinity 在**同等模型能力**下，多做的是供应、调度与治理——不只是换一个网址：

| 维度 | 只接一家原厂 API（常见） | 用 Trinity |
|------|--------------------------|------------|
| 可用性 | 单路径，抖动易卡住、空等 | 多源冗余 + 异常自动切换 |
| 高峰表现 | 公共池易挤兑、限流 | 容量预留思路 + 负载感知调度 |
| 接入成本 | 多厂商就要多套协议、多套对接 | 统一兼容协议，多模态一站接入 |
| 综合成本 | 标价公开、议价空间有限 | 深度合作，综合单价更有优势 |
| 可观测 | 因厂商而异 | 统一看用量、追踪与对账 |
| 企业治理 | 权限、密钥、分摊往往要自建 | 鉴权、密钥、费用治理开箱可用 |

**AI 云差异点（相对「自己上官网散买」）**

- 集采级折扣与灵活账期，**零门槛 / 零保底 / 零承诺**  
- 统一账单与开票、专人对账  
- 免费咨询与架构设计，渠道 VIP 响应  

一句话收束：

> **选择 Trinity，不只是换一个下单入口——云侧买得省、管得清；模型侧同等能力下，高峰更稳、接入更短、成本更可控。**
