# Trinity · marketing

线下/外发营销物料（**不随官网 Web 发布**）。

## 一眼找

| 要什么 | 去哪 |
|--------|------|
| **拿 PDF 给客户/销售** | [`销售套件/`](./销售套件/) |
| **改 Deck / A4 / 建议书** | [`销售真源/`](./销售真源/) |
| **改服务号推文 / 选型叙事** | [`营销服务号/真源/`](./营销服务号/真源/) |
| **拿服务号定稿 PDF** | [`营销服务号/可对外/`](./营销服务号/可对外/) |
| **他司/历史大文件** | [`参考物料/`](./参考物料/) |
| **导出工具** | [`tools/`](./tools/) |

```text
marketing/
├── 销售套件/          ← 成品 PDF + 清单
├── 销售真源/          ← Deck · 建议书 · 展会印刷（按文件夹）
├── 营销服务号/
│   ├── 真源/          ← 推文 · 选型叙事
│   └── 可对外/        ← 推文定稿 PDF
├── 参考物料/
└── tools/
```

工作流：改真源 → 导出 → 覆盖对应成品目录（销售套件 / 营销服务号/可对外）。
