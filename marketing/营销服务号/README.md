# 营销服务号

一眼区分：

| 目录 | 含义 |
|------|------|
| **[`真源/`](./真源/)** | 只改这里 · 默认不外发 |
| **[`可对外/`](./可对外/)** | 定稿 PDF · 可发服务号后台 / 转发 |

```text
营销服务号/
├── 真源/
│   ├── 推文/           ← 现行 md · docx · 归档/
│   └── 选型叙事/       ← 为什么选择 Trinity…
└── 可对外/             ← 推文 PDF
```

## 重导推文 PDF

```bash
# trinity-AI 根目录
python3 marketing/tools/export_md.py \
  "marketing/营销服务号/真源/推文/公众号-Trinity品牌介绍-AI云与API聚合.md" \
  --pdf -o "marketing/营销服务号/可对外"
```

销售印刷 / Deck 成品在 [`../销售套件/`](../销售套件/)，不放本目录。
