# 财务分类账 · 产品设计（Ops Desk）

> **更新**：2026-10-26  
> **目的**：按财务「收入分类账 / 支出分类账」模板单独出一页，与运营「消耗台账」分开；财务口径有变时只改本模块可编辑字段。

## 1. 与现有模块边界

| 模块 | 给谁 | 口径 |
|------|------|------|
| 消耗台账 | 运营 | 客户 × 云 × 账期明细，开票联动 |
| 出付款申请 | 运营 | 打给上游云厂的付款单 |
| **财务分类账** | 财务 / 运营交财务 | 月度汇总：期初 + 充值 − 消耗(±服务费) = 余额 |

## 2. 页面结构（对齐财务 Excel）

1. **收入分类账 · 人民币**：客户公司（远景 / 亿点 / 山河…）  
2. **收入分类账 · 美元**：FAR / Fengyee 等  
3. **支出分类账 · 人民币**：阿里云 / 腾讯云 / 华为云 / 数据宝…  
4. **支出分类账 · 美元**：垫付 U 等  
5. **附注**：腾讯云/阿里云 · 星瀚服务器成本（可编辑）

## 3. 字段与数据来源

**原则：有实际数据才汇总；无法汇总的字段保持空（null），不填 0。**

| 字段 | 收入 CNY | 支出 CNY | 可改？ |
|------|----------|----------|--------|
| 期初余额 | 暂无来源 → 空 | 暂无来源 → 空 | ✅ 手填 |
| 本月充值 | 暂无来源 → 空 | **有数**时从出付款「用途月」按云汇总 | ✅ |
| 本月消耗 | **有数**时从客户结算**按公司**汇总 | **有数**时从客户结算**按云厂商**汇总 | ✅ 覆盖 |
| 服务费 | **有数**时从客户结算汇总（仅收入） | — | ✅ 覆盖 |
| 美元消耗 | Trinity Invoice（FAR / Fengyee）有数才填 | — | ✅ |
| 附注星瀚阿里 | 星瀚结算·阿里云有数才填；腾讯星瀚暂空 | | ✅ |
| 余额 | 有任一数字时：`期初+充值−消耗−服务费`（空当 0）；全空则余额也空 | 同左 | 只读 |
| 备注 | 手工 | 手工 | ✅ |

## 4. 存储

SQLite 表 `finance_ledger_lines`：按 `month_key + book + party_key` 存覆盖值（opening/recharge/consume/fee 均可 NULL）。  
未覆盖时 GET 用结算 / 出付款 / Trinity 自动拼出，无数字段为 null，不落库。

## 5. 导出

一键导出 Excel，版式贴近财务模板（收入 CNY/USD + 支出 CNY/USD + 附注）。
