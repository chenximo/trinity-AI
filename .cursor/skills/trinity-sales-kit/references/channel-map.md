# 渠道取句表

先选一行再写。禁止把 GEO 长文贴上展架。新视觉版式见 [`print-design.md`](./print-design.md)。

| 渠道 | 3 米外 | 1 米内（有出处） | 明确不取 |
|------|--------|------------------|----------|
| **一纸禅** | 一句主标 | ≥3 个词级锚点（如统一入口 / 100+ / 一套 Key）+ 域名；版式三选一看图 | 能力长段、适合谁卡片、不适合谁、对比、联系人堆、99.9% SLA、降本增效、空页只留一句 |
| 站台海报 100×200 | 主标 | 能力 ≤5 + 适合谁 ≤3 或等价锚点 | 不适合谁全文、竞品长对比、English Summary、未拍 SLA |
| A4 双面 | 产品名 | 正面 API、背面云、场景 + CTA | 深折表、内部 Excel |
| 宣讲 / 品牌 Deck | 页标题 | 按大纲；上屏约 6 行 | 另做厚案例册；口述全文上屏 |
| GEO `/apps` | 定位句 | 适合/不适合、品类对比、以文档为准 | 展会口号、双引擎云×API（海报 v1 线） |

**一纸禅过关**：3 米外仍是一句；走近不是空白。留白是构图，不是没内容。
