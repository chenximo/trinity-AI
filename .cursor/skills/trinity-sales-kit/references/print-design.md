# 印刷视觉（从 huashu-design 收来的几条）

来源：[alchaincyf/huashu-design](https://github.com/alchaincyf/huashu-design)。**不整仓安装、不抄 60 种风格全文。** 只收下面这些。

## 必借

| 条 | 做什么 | 不做什么 |
|----|--------|----------|
| **三版看着选** | 新海报 / 一纸禅 / 新 A4 版式：先出 **3 个可打开的 HTML**，用户看图选后再深化 | 在对话里用文字描述风格让人盲选；指定「一纸禅」也不只出一版空页 |
| **禁止三版同温** | 一版安静留白、一版网格、一版信息图密度 | 三张都是白底一句；模型默认偷极简 |
| **印刷 = 信息图** | 100×200 / A4 按信息图排（层级、网格、数据墨水） | 套网页落地页：圆角大卡、紫渐变、emoji 列表 |
| **密度分型** | Trinity 是 API/数据产品：展架 **3 米外一句主标，1 米内 ≥3 处有出处的锚点** | 把「克制」做成空页；用装饰 icon/假 stats 凑密度 |
| **留白是构图** | 锚点靠网格或黄金位；留白有形状 | 中间一句、四周空洞（花叔：做过头像页面坏了） |
| **资产不猜** | wordmark、`trinity-base` / 现有海报色、现网 UI | 另起青紫霓虹科技风；CSS 剪影冒充产品 |
| **反 slop** | 无 emoji 作图标、无「圆角卡 + 左边色条」、无编造数字 | Trinity `--grad` 是品牌签名，**不算** slop |

## 不借

iOS 机框、MP4/PPTX 工具链、60 风格库当菜谱、任何新视觉 100% 先三方向（**改一句 / 改一页走捷径**）、禁紫渐变当死条。

## 三版默认标签（海报打样）

| 方向 | 气质 | 1 米内必须能扫到 |
|------|------|------------------|
| A 留白构图 | 原研哉「间」：少元素、大字号、边位锚点 | 主标 + 3 个词级锚点 + 域名 |
| B 瑞士网格 | 发丝线分栏、字号极端反差、高密度不挤 | 主标 + 五条能力短句 + 厂商名 |
| C 信息图 | 标题即结论、编号要点、计量三格 | `/apps` 五条能力 + 1 API / 100+ / 一套 Key |

文案仍只抽 `channel-map` + `/apps` / 营销总册；红线仍归 `sales-kit.md`。
