# 讲解 Deck / brand-deck

工序真源：`docs/08-方法论与汇报/讲解Deck-四步生成范例.md`（本 Skill **允许** Cursor 写大纲与定稿；人只锁闸）。

1. READ 范例 §改字路径 + 现有 `marketing/brand-deck/目录.md` 与 `Trinity产品介绍.md`（或 `sales-deck-outline.md`）。
2. 闸 1：听众/场合/时长不清且不是「改第 N 页」→ 先问。改一句/一页 → 跳过。
3. 先交或改 **大纲/定稿 md**（上屏 / 口述或销售备注 / 不上屏）。数字无出处标「待补」。
4. 闸 2：用户未冻定稿 → **不灌** `index.html`、不改 `output/` PDF。
5. 冻结后：上屏只取「PPT 上的字」写入 `index.html`；复用现成 `deck.css`。
6. 导出仅当用户要求：`marketing/brand-deck/export_deck_pdf.sh`。

品牌介绍主文件是 HTML；销售宣讲大纲在 `sales-deck-outline.md`（可灌 pptx）。新讲解册默认跟 HTML 四步。
