# trinity-sales-kit · 领域边界

## 本 Skill 管什么

- 可打包发给客户或销售随身带的物料：站台海报、一纸禅、A4、brand-deck 文案与 HTML、案例示意页、报价/异议**骨架**
- 从 `/apps`、Pricing、手册**抽句**到上述物料
- 版本线：冻旧版、新文件打样

## 本 Skill 不管什么

| 不归本 Skill | 交给 |
|--------------|------|
| 官网 Vue 营销页、方案矩阵 | `trinity-tob-marketing-site` |
| 手册结构、周会、roadmap | `trinity-product-handbook` |
| 对外 API 文档正文 | `trinity-docs` |
| 刊例、写价、L3b 数字算法 | `trinity-official-pricing` |
| 色板 / 按钮原子 | `trinity-design-tokens`（印刷件复用现有 HTML 主题） |

## 与七件套文档

`sales-kit.md` 是套件**清单真源**。本 Skill 不复制七件全文，只规定怎么写、从哪抄、哪两闸。
