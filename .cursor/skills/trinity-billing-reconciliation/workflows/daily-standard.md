# 标准日结与月桶（差大时）

## 何时用

L0 落入「下钻」，或用户明确要求按日核（尤其腾讯 L2）。

## 规则

1. **标准日结**：开始使用日 = 结束使用日，且扣费时间完整。  
2. 对齐：上游使用日 ↔ 平台结算日。  
3. **月桶**：跨日或扣费 `-` → 只进月合计，**禁止均摊到日**。  
4. 日表列双方量与金额。  
5. **疑似测试**：标准日结且上游$ > 平台$；平台接近空 = 高置信。

## 产出

`YYYY-MM/daily-standard-settlement-YYYYMM.md`（可选 `.csv`），并回写报告/notes。

下钻完成前，不建议「确认回填后台」。
