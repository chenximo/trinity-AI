# 月度 L0 闸门（量 + 金额）

> 被 [`./generate-report.md`](./generate-report.md) 调用；也可单独解释阈值。

## 比什么

| 项 | 平台 | 上游 |
|----|------|------|
| 金额 | 平台成本 USD | 实付 USD（CNY÷6.5 或用户给定） |
| 量 | Token 入+出+缓 | 用户声明口径的上游 Token |

详见 [`../references/metrics.md`](../references/metrics.md)、[`../references/fx-and-cost.md`](../references/fx-and-cost.md)。

## 默认阈值

| 档 | 条件 | 报告结论倾向 |
|----|------|----------------|
| 预期内 / MATCHED | \|金额差\|≤5% 且（无 Token 或 \|量差\|≤5%），或绝对额 ≤$10 | 可建议回填 |
| 关注 | 金额差 5%～15%（量不大） | 写明疑刊例等；回填须人确认 |
| 下钻 | \|金额或量差\|>15%，或绝对额 >$50，或倍数 ≥2× | 先下钻再谈回填 |

## 拆解叙事（可选）

若量差约 A%、金额差约 B%，可写「量约 A%，其余约 B−A 归价格/其它」——须基于本次数字，禁止编造精确归因无证据。
