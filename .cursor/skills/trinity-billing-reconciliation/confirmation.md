# 确认规则 · trinity-billing-reconciliation

先读 [`../common/confirmation.md`](../common/confirmation.md)。

## 本 Skill 须确认

| 操作 | 说明 |
|------|------|
| 对外 / 周报定稿采用报告结论 | 客户或管理层可见前 |
| 改默认对账汇率（非 6.5） | 影响闸门 |
| 将结论标为「可回填后台 / ADJUSTED 认损耗」 | 财务含义；仍由人点后台 |

## 禁止（无确认也不做）

- 调用或指导自动化 **写入** 管理后台上游实付（除非用户明确要求且具备工程权限任务——默认拒绝，改为给出应填数字清单）

## 不需要确认

- 读平台 CSV / 用户粘贴的上游数字
- 生成或更新 `YYYY-MM` 下报告草稿、`notes.md`
- 聊天里讨论差%、阈值
