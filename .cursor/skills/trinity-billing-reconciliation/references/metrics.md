# 量与金额指标

## 平台（后台导出）

| 指标 | 口径 |
|------|------|
| 成本 | `平台成本(USD)`；排除合计行 |
| Token | **入 + 出 + 缓**（不含写缓存则注明） |
| 期间 | 统计起止 / 账单月 |

## 上游（人工账单）

| 指标 | 口径 |
|------|------|
| 实付 | 现金 CNY；赠金单列 |
| USD | 用户给定或 ÷ **6.5** |
| Token | 须声明；与平台可比 |

## 差

\[
\text{金额差\%} = \frac{\text{上游USD} - \text{平台成本USD}}{\text{平台成本USD}} \times 100\%
\]

量差% 同理（分母为平台 Token）。
