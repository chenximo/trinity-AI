# 核对报告模板（报告先行）

## 单上游 · 单月

```text
<供应商名> 账单核对：

<月>账单：
上游官方实际是 $ X（¥Y），token 消耗总数为 …百万（口径：…）
Trinity 平台成本记录 $ Z，token 消耗总数为 …百万（入+出+缓）
花费总额差异 …，token 差异 …（若有）
原因：
1）…
2）…
结论：…（预期内 / 关注 / 待下钻）

确认后可回填管理后台实付：¥Y / $X
（本报告不自动改后台）
```

## 多月可并列

同供应商下按月追加；最后可写总结论。

## 检查清单

- [ ] 上游 / 平台左右正确；¥ 只在上游
- [ ] 双方金额 + Token（或缺省说明）
- [ ] 窗口 / 完整月未出已声明
- [ ] 有「是否建议回填」与应填数字
- [ ] 未声称已更新后台

## 反例

```text
# 错：¥ 写在平台
trinity 平台成本记录 $218（1417¥）

# 错：未确认就写
已更新管理后台实付
```
