# 管理后台月度表 · 字段口径

> 工程加列按本表；对账时 Skill 读导出，**不写实付**。

## 对账前（系统自动）

| 字段 | 说明 |
|------|------|
| 上游编码 / 名称 | 已有 |
| 账单月 | 建议有 |
| 统计起止 | 结算日 min～max |
| 平台成本(USD) | 已有 |
| 平台成本(CNY) | 可选展示；对账主比 USD |
| **平台 Token 合计** | **待加**：入+出+缓，脚注口径 |
| 上游实付(USD/CNY) | 对账前可空，状态 PENDING |
| 差额 / 状态 | 回填后更新 |

## 对账后（人工，确认报告后）

| 字段 | 说明 |
|------|------|
| 上游实付(CNY/USD) | 按报告应填数字 |
| 差额(USD) | 系统或手算 |
| 状态 | MATCHED / ADJUSTED 等 |
| 备注 / 附件名 | 可选；链报告文件名 |

## 不必强求进后台（可只在报告里）

上游 Token——报告必有；是否落库可选，方便历史查询时再加。
