# 结算确认单

正式对外云账单：**《云服务结算确认单》**。

| 路径 | 说明 |
|------|------|
| [`模板/结算确认单.doc`](./模板/结算确认单.doc) | 正式 Word 模版（与桌面稿同步；另有 docx） |
| `{客户标签}/{YYYYMM}/云服务确认单_{公司}_{账单日起}.pdf` | Ops Desk 按公司×月份导出的成品 |

## 如何导出

1. 启动 Ops Desk（前端 5177 / API 8787）  
2. **消耗台账** → 选公司 + **具体账期**（勿选「全部」）→ **导出云服务确认单 PDF**  
3. 浏览器下载的同时落盘到本目录  

API：`GET /api/cloud/settlement-confirm.pdf?customer=亿点&period=202609`  
命名例：`云服务确认单_北京山河聚量科技有限公司_20260901.pdf`

## 口径

- 标题：**云服务确认单**；甲方固定 **陕西星瀚算力信息科技有限公司**  
- 乙方：客户结算对应全称（开票抬头库 / customers）  
- 结算周期：账期自然月首末日（如 202609 → 2026年09月01日–30日）  
- **明细表头**对齐客户结算原表：业务所属期 / 账号信息 / 实际消耗 / 服务费比例 / 服务费金额 / 结算总金额 / 备注（一行一账号）  
- Akamai 等 USD 不进人民币合计，写在说明第 4 条  
- 计费模式：按量计费
