# Akamai / Linode 对账

与腾讯云 / 阿里云 / 华为云并列：海外边缘云（Akamai Linode）上游账单与发票。

**客户结算金额**写入 [`../客户结算/`](../客户结算/) 对应公司表（云厂商=`Akamai`，币种 **USD**，与人民币云分开合计）。  
**发票 PDF** 放本目录。

```text
Akamai对账/
└── <客户>/
    └── YYYY-MM/
        └── 发票/
            └── 20261001_USD…_Invoice-…_<账号>.pdf
```

| 客户目录 | 对应结算表 | 账号例 |
|----------|------------|--------|
| `亿点/` | `客户结算/亿点云业务消耗费用.xlsx` | Adnov · AceMedia |

Ops Desk「消耗台账」选公司后，云厂商筛选项会扫出 `Akamai`（来自结算表明细）。
