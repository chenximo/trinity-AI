### 工作簿结构

| Sheet | 内容 |
| --- | --- |
| **明细** | 多云合表：业务所属期 / 云厂商 / 账号信息 / **币种** / 实际消耗（原币） / 服务费比例 / 服务费金额（原币） / 结算总金额（原币） / 备注 / 服务费是否支付 |
| **月度汇总** | ① 按月 × 云；② 每月总消耗（全云合计）；③ 全部期间合计 |
| **腾讯云** | 原单云写法：按月列出账号；**多账号客户（如 hehe）每月一块并带当月合计** |
| **腾讯云_YYYYMM** | hehe：与历史「每月一表」一致的单月 sheet（主账号 / 程序化 / 网盟 + 当月合计） |
| **阿里云** | 原单云写法（按月）：业务所属期 / 账号信息 / 实际消耗 / 备注（无服务费） |
| **华为云** | 同阿里云短表；目前仅 hehe |
| **华为云_YYYYMM** | hehe：单月 sheet（与历史分月表对应） |
| **Akamai** | Linode 月结（**USD**）；按账号分行；票在 `../Akamai对账/` |

**月份顺序（hehe 及后续录入）**：明细 / 月度汇总 / 各云汇总表内，以及 `腾讯云_YYYYMM` · `华为云_YYYYMM` 标签，均 **最新月在前**（新→旧）。

### 口径

- **腾讯云**：服务费 2%；结算总金额 = 实际消耗 + 服务费；备注「真实消耗已预充值」
