# 腾讯云对账

各客户腾讯云账号服务费结算表。口径与 hehe 一致：服务费比例 2%，结算总金额 = 实际消耗 + 服务费，备注统一为「真实消耗已预充值」。

| 子目录 | 账号信息 | 说明 |
| --- | --- | --- |
| `hehe/` | 主账号 / 程序化账号 / 网盟账号 | 多账号，按月分表 |
| `亿点/` | 亿点宇宙（陕西）信息科技有限公司 | 单账号，7/8 月合并一张表 |
| `BID/` | BID账号 | 单账号，7/8 月合并一张表 |

列：业务所属期 / 账号信息 / 实际消耗 / 服务费比例 / 服务费金额 / 结算总金额 / 备注 / 服务费是否支付。

- `hehe/`：按月一份 `腾讯云_服务费结算_YYYYMM.xlsx`
- `亿点/`、`BID/`：各一份 `腾讯云_服务费结算.xlsx`（多月同行，末列「服务费是否支付」待填写）
