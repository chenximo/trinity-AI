## 1. 标准七件套（业界通用）

一套 **ToB / 标准化产品**公认的「销售 7 件套」：

| # | 件 | 用途 | 典型场景 |
|---|-----|------|----------|
| 1 | **产品一页通（One Pager）** | 痛点、价值、功能、客群、优势 | 首次拜访 / 首次发客户 |
| 2 | **宣传手册 / 画册（Brochure）** | 公司、架构、功能、场景、技术优势 | 跟进、展会带走 |
| 3 | **方案 PPT｜销售宣讲 Deck** | 讲解主线 | 面谈、线上 Demo |
| 4 | **客户成功案例集（Case Study）** | 同行落地、投入产出、效果 | 建立信任 |
| 5 | **报价方案模板（Proposal）** | 档位、规格、周期、增值、条款骨架 | 进入商务 |
| 6 | **FAQ + 异议应对手册** | 高频疑问、竞品要点、标准应答 | 全程 |
| 7 | **合作协议 / 意向书模板** | 意向框架 → 正式合同 | 推进签单 |

**Trinity 精简落地（已拍）：**

| 业界 | Trinity 做法 |
|------|----------------|
| 1 + 2 | **合并** → 一份 **A4 双面宣传单**（主宣传件） |
| 3 · 4 | **本阶段主做** → [Deck 大纲](./sales-deck-outline) · [案例/场景示意](./case-studies) |
| 5～7 | 暂缓 |

**线上发给客户（本阶段目标）：**  
A4 PDF + 宣讲 PPT + 案例/场景示意页。

**线下（展会 / 上门）：**  
A4 印刷件、站台海报、名片；宣讲用 Deck。

> Trinity 为 API / 开发者平台，**第 7 件仍用协议模板**（不换成实物样品册）。

## 3. 产品经理要重点提供什么 {#pm-deliver}

PM **不是**替销售做完所有设计稿，也 **不是**法务合同终稿作者。PM 提供的是：**口径、骨架、清单、红线、验收标准**，并拉动市场/商务/法务出成品。

### 3.1 必须由 PM 拍板 / 维护的（真源）

| 交付物 | 说明 | 真源落点 |
|--------|------|----------|
| **对外叙事一句话** | Trinity 是什么、不解决什么 | 营销总册 · **A4 主宣传件**文案 |
| **浅/深边界** | 页上与客户附件 **禁止**出现的折数/成本族 | [营销总册 §边界](./pricing-marketing-strategy#boundary) |
| **四档对外话术** | 标准/进阶/成长/企业 · 「最高可省」% | [营销总册 §2.5](./pricing-marketing-strategy#page-ia) |
| **场景主推清单** | 性价比 / Coding / 多模态 · 真模型 ID | [Playlist](./marketing-scene-playlist) |
| **试用 / 老带新规则** | 额度、期限、是否写死数字（待拍则标「联系商务」） | [试用方案](./new-user-trial-scheme) · 营销总册 |
| **销售能说 / 不能说** | 竞品对比尺度、延迟承诺、SLA 口径 | 本页 §3.3 + 异议手册骨架 |
| **七件套缺口与优先级** | 谁补、何为完成定义 | 本页 §2 · §4 |
| **对内算折真源指引** | 销售查折只走 Excel，不靠口头 | [证据链](./pricing-strategy-evidence-chain) · [Excel SOP](./discount-tier-workbook-sop) |

### 3.2 PM 出「内容骨架」，市场/设计出「版式成品」

| 件 | PM 提供 | 市场 / 设计 / 销售 | 法务 |
|----|---------|-------------------|------|
| 1+2 主宣传件（A4） | 与营销总册对齐的文案审定；版本/日期 | 维持 A4 HTML→PDF；展会印刷 | 主体表述复核 |
| 3 Deck | **15 页大纲 + 备注**（见 [sales-deck-outline](./sales-deck-outline)） | **品牌 pptx 母版灌入**、动画 | — |
| 4 案例 | 场景示意嵌 Deck P09；真实案例标准与脱敏 | 示意进 PPT；成册后补 | 引用客户名审阅 |
| 5 报价模板 | **字段表**（档位、Credits、周期、服务项、不含深折）；与四档对齐 | 可编辑 Word/PDF | 商务条款底稿 |
| 6 异议手册 | **Q 列表 + 标准答 + 红线**（可先 Markdown） | 可印口袋卡 | 合规相关答法审 |
| 7 协议 | 业务条款需求清单（试用额度、计费、责任边界） | — | **模板起草与定稿** |

### 3.3 PM 必守红线（写入异议手册首页）

| 红线 | 说明 |
|------|------|
| ❌ 客户附件含商务深折表 / 成本族 | Excel `01` 仅销售内部 |
| ❌ 承诺未上线 SLA / 未拍数字 | 试用、老带新未拍则只写「联系商务」 |
| ❌ 把「最高可省」写成固定折数 | 页上与报价均为示意；开通走商务 |
| ❌ 竞品延迟/吞吐硬对打无实测 | 可用定性「访问与调用体验持续优化」 |
| ✅ CTA 统一 | 试用 / 充值档 / 大客 → **联系商务** 或官网 Pricing |

### 3.4 PM 验收「一件齐了」的定义

| 件 | Definition of Done |
|----|-------------------|
| 1+2 | **A4 PDF 可发邮件 / 可印刷**；文案与营销总册一致；有版本号；**不要求**另出一页通或多页画册 |
| 3 | PPT 可投屏；备注页有讲解顺序；无内部 GM/深折 |
| 4 | ≥1 篇可外发案例 **或** 标明「场景示意、非签约客户」的过渡页 |
| 5 | 客户向可填模板；**不附**洽谈总表；四档与营销页一致 |
| 6 | 销售可检索的 FAQ+异议 Markdown/PDF；含红线页 |
| 7 | 法务审过的意向书（+ 可选合同初稿）可填空发送 |
