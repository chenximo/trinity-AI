## 1. 十五页定稿 {#pages}

### P01 · 封面

- **页上**：Trinity · AI API 聚合  
  **一个 API，接入百余模型**  
  副标：预付费按量 · 企业管控 · IDE 一键接入  
- **备注**：自报身份；确认今日目标（了解 / 试用 / 商务）。口头带过议程即可，**不要单独议程页**。

### P02 · 你们可能正在面对

- **页上**：多厂商接口不一 · 账单分散 · 选型反复试错 · 成本与权限难管控  
- **备注**：各举一句场景化例子；不点名贬低竞品（可说「多套 SDK / 多份账单」）。

### P03 · Trinity 是什么

- **页上**：独立的 AI API 聚合 · **一个 OpenAI 兼容 API** · 按量调用多家模型 · 同一产品完成计费与团队管控  
- **备注**：与厂商无官方关联；价目以模型目录为准。

### P04 · 核心价值

- **页上**：① 统一接入 ② 预付费按量 ③ 按场景选择模型 ④ 企业管控（工作区 / 成员 / Key / 限额）  
- **备注**：每条一句；可带一句 `auto` / Memory「帮助降低浪费」（**不报死省钱比例**）。

### P05 · 谁适合用

- **页上**：开发者团队 · 要控成本的业务 · 要权限与限额的企业负责人 / IT  
- **备注**：可诚实说不适合「只绑单一厂商且无聚合诉求」的客户。

### P06 · 能力地图

- **页上**：模型目录 → API / IDE 接入 → 控制台（工作区·成员·Key·额度·用量）→ Docs  
- **备注**：可提 `trinitydesk.ai` · `doc.trinitydesk.ai`。

### P07 · 怎么接入

- **页上**：注册登录 → 创建 Key → Base URL + 模型 ID → 调通  
  IDE：Cursor / Claude Code 等 · `trinity-config` / Cookbook  
  体验：模型目录 · Quickstart · 控制台用量  
- **备注**：现场能打开官网/Docs 就演示；否则约跟进。Demo 不单开一页。

### P08 · 场景精选

- **页上**（三列，对齐 Playlist）：

| 场景 | 一句话 | 代表方向（以目录为准） |
|------|--------|------------------------|
| 性价比 | 日常对话、批处理 | Qwen Flash 等 |
| AI Coding | 写代码、Agent、IDE | gpt-5.3-codex、Qwen Plus 等 |
| 多模态 | 图文 / 生视频 | GPT-4o / 5.x、seedance 等 |

- **备注**：卖场景不卖折数；视频 **不讲折扣**。

### P09 · 场景示意（案例位 · #4）

- **页上**：三则压缩卡——性价比高频 / Coding+IDE / 多模态统一网关（详见 [case-studies](./case-studies)）  
- **脚注（必须）**：**场景示意 · 非签约客户案例** · 模型以官网为准  
- **备注**：不编造公司名；有真实案例后再替换本页。

### P10 · 怎么买

- **页上**：预充值 Credits → 按量扣费 · USD  
  充值档位越高，商务可谈空间越大（开通走商务）  

| 档 | 门槛示意 | 页上说法 |
|----|----------|----------|
| 标准版 | &lt; $1k | 起步 · 刊例 |
| 进阶版 | ≥ $1k | 最高可省约 10% |
| 成长版 | ≥ $10k | 最高可省约 18% |
| 企业版 | ≥ $100k | 最高可省约 28% |

- **备注**：脚注「最高可省」非固定折数；中间档私下谈；**不讲自助自动达档**。

### P11 · 企业管控

- **页上**：顶级 / 子工作区 · 成员邀请 · 模型权限 · API Key · 子区消费限额 · 用量查看  
- **备注**：对准「怕超支、怕 Key 乱飞」。

### P12 · 为什么选 Trinity

- **页上**：对照 P02——一个 API · 少账单 · 场景清晰 · 可管可控 · 预付费透明  
- **备注**：逐条打勾，短讲。

### P13 · 下一步

- **页上**：① 带走 / 发送 A4 ② 看 Pricing ③ 联系商务开通试用或商务档 ④ 约定技术对接时间  
- **备注**：留联系方式与跟进日。

### P14 · 资源入口

- **页上**：官网 · Pricing · Docs / Cookbook · 产品动态 · A4 宣传单  
- **备注**：需要合规时口头指 Privacy / Terms，不展开法律意见。

### P15 · 封底

- **页上**：Trinity · 感谢 · 联系方式 / 二维码 · 官网  
- **备注**：Q&A；需要时翻回对应页。
